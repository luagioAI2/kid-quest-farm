# 家长密码闸门（2026-11-06 统一定稿）

> 一句话：**需要家长密码的地方，一律是「一颗按钮 + 一个弹框」，键盘不许铺在页面里。**

用户原话：「需要家长密码的，能否统一成弹框的样式，比如点眼睛时候那样。」
（👀 = 顶栏那颗家长审核入口，它的弹层就是标准形。）

## 唯一实现

`src/features/parent/ParentGate.tsx`：

| 导出 | 干什么 |
| --- | --- |
| `ParentPinSheet` | **输密码的弹框**（`Sheet` + `SheetHead` + `PinSheetBody`）。全 App 只有这一个输密码界面 |
| `PinSheetBody` | 弹框里那一块（副标题 + 键盘），不带标题 —— 标题归外层 `SheetHead` |
| `ParentLockButton` | 「👤 爸妈：…」按钮，带 `data-parent-lock` 标记，点开 `ParentPinSheet` |
| `parentPinCopy` | 标题/副标题/图标口径（第一次用家长区时标题要变成「先设一个家长密码」） |
| `ParentPinPanel` | 内联面板（带 🔒 + 标题）。**只剩一处**：去激活弹框（经 `ParentGate` 包一层）。它外面没有别的标题，所以这里自带标题是对的 |
| `ParentGate` | 包一层：要密码就先显示面板，通过后渲染 children（去激活弹框在用） |

## 七处闸门

| 位置 | 锁着的时候 | 过了闸 |
| --- | --- | --- |
| 心愿详情 · 实物 `committed` | `👤 爸妈：确认兑换 · 去购买`（主按钮样式） | 真按钮「确认兑换 · 去购买」 |
| 心愿详情 · 数字商品已交付 | `👤 爸妈：完成这一单` | 真按钮「完成这一单」 |
| 心愿详情 · 已许愿待定价 | `👤 爸妈：回应这个心愿` | 真按钮「🎫 定个价」 |
| 心愿 · 家长定价页 | 锁卡 + **弹框自动打开**（点「定个价」进来第一眼就是密码框） | 定价页 |
| 兑换 · 管理 tab | 锁卡 + `👤 爸妈：管理兑换品` | 管理面板 |
| 设置 · 规则 / 游戏 / 数据 | 锁卡 + `👤 爸妈：输密码` | 对应 tab 的内容 |
| 顶栏 👀 / 任务编辑器 | 已经是弹层，里面直接摆键盘；**标题归 `SheetHead`**（锁定态说「请爸爸妈妈来一下」，过了闸才换成「改一改任务 / 加一个新任务」） | 内容 |
| 去激活弹框 | 里面是 `ParentGate` → `ParentPinPanel`（自带标题，外层只有「激活『X』」） | 输码框 |

## 三条不能破的规矩

1. **真按钮只能在过闸之后渲染。** 让真按钮和锁按钮同时出现，那颗真按钮就是假闸门
   —— 点了照样能改价/收尾，密码等于没设。
2. **取消 ≠ 解锁。** `onClose` 只关弹框，`pinOk` 不动；下一次还得输。
   （唯一例外：定价页的「先算了」= 退回商品详情，和它原来那颗取消按钮一致。）
3. **弹框里不许再摆一块带标题的面板。** 👀 原来就是 `SheetHead` 出一个标题、
   `ParentPinPanel` 又出一个 —— 屏幕上两个 🔒、两个「请爸爸妈妈来一下」
   （2026-11-06 截图抓到）。标题只由外层出，里面只放 `PinSheetBody`。

## 为什么不能把键盘铺回页面里

- 孩子扫一眼就看见键盘，会以为这一屏坏了（没有任何可点的东西）；
- 键盘占满第一屏，家长看不到「为什么需要密码」的上下文（是定价？是收尾？）；
- 页面高度被撑开，底部导航被挤出屏幕（390×844 上键盘 + 标题 ≈ 560px）。

## 怎么验

- 单测：`WishPage.test.tsx` 的「心愿：家长密码是一个弹框…」、`RedeemSheet.test.tsx`
  的「兑换：管理 tab 的家长密码是弹框」——三条**成对**断言：
  ① 页面上没键盘、没真按钮；② 点锁按钮才弹框、**输错不放行**；③ 输对才出现真按钮。
- 走查：`scripts/_probe-pin-dialog.mjs`（16 条）—— 含「弹框压得住底部导航」
  （`elementFromPoint` 判据，不是 z-index）和「取消不等于解锁」。
- 走查：`scripts/_probe-pin-task-editor.mjs`（9 条）—— 任务编辑器锁定态**正文里
  「请爸爸妈妈来一下」只能出现 1 次**（出现 2 次 = 标题又叠回去了），
  且这时不许出现「加一个新任务」（闸门没开就亮真标题 = 提前泄底）。
- e2e：`scripts/e2e-wishmall.mjs` 的 `openPin()` —— **先点 `[data-parent-lock]` 再输**。
  只调 `passPin` 会在一个没有键盘的页面上空按 4 次「0」，然后报「定价需要家长密码」失败，
  看着像闸门被删了。
